# FeWo Bakilala
Statische Website der Ferienwohnung in Kippenheim, live unter https://fewo-bakilala.com (GitHub Pages).

- `index.html`: Startseite Deutsch
- `en/index.html`: Englisch, `fr/index.html`: Französisch
- `impressum.html`, `datenschutz.html`: Rechtstexte (nur Deutsch)
- `style.css`: Design aller Seiten, `main.js`: Animationen, `images/`: Fotos

Wenn du einen Text änderst (z. B. Preise oder Check-in-Zeiten), ändere ihn in allen drei Sprachversionen.
